# Contributing and updating this portfolio

This is a personal research portfolio. Suggestions and corrections are welcome.

## Before publishing
- Remove all placeholders and private information.
- Confirm you have permission to share each dataset, figure and script.
- Add citations for datasets, methods and software.
- Include an environment or requirements file where appropriate.
- Keep large raw data and generated intermediate files out of Git.
- Clearly distinguish real experimental results from simulated demonstrations.
- Check that the README accurately reflects your own level of experience.

## Suggested commit messages
- `docs: add research profile`
- `feat: add genomic prediction workflow`
- `fix: correct phenotype preprocessing`
- `data: add public dataset citation`
