# KASP Marker Development and Molecular Breeding

**Status:** planned / in-progress / completed

## Objective
Document the development and validation of allele-specific markers for a target trait.

## Workflow
1. Define trait, mapping evidence and target allele.
2. Select candidate polymorphism(s) and inspect flanking sequence.
3. Design candidate KASP assays using the provider's current design requirements.
4. Test assay performance on suitable controls and representative germplasm.
5. Evaluate cluster separation, call rate, reproducibility and concordance.
6. Validate marker–trait association in an independent or appropriate breeding set.
7. Document limitations and intended selection use.

Do not upload proprietary primer/assay information or unpublished germplasm data without permission.
